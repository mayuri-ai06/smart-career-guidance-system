# 🎓 Smart AI Career Guidance System

An intelligent web application that predicts a student’s suitable career path using **Machine Learning** and generates a **personalized 3-month learning roadmap using Google Gemini AI**.

This project helps students who are confused about their future career by analyzing their interests and providing clear direction, skills, and learning resources.

---

## 🚀 Live Demo

*Add your Streamlit deployed link here(https://smart-career-guidance-system-m.streamlit.app/)

---

## 📌 Features

✔ Career prediction using Machine Learning model
✔ Interest analysis (Maths, Biology, Commerce, Creativity)
✔ Manual override logic for better accuracy
✔ AI-generated 3-month roadmap (Gemini API)
✔ Skill explanation for each career
✔ Resume skill suggestions
✔ Student data stored in CSV database
✔ Visual skill analysis chart
✔ Downloadable personalized career report

---

## 🧠 Technologies Used

* Python
* Machine Learning (Scikit-learn)
* Streamlit (Web App)
* Google Gemini API (AI Roadmap Generator)
* Pandas (Data Handling)
* Matplotlib (Visualization)

---

## ⚙️ System Workflow

1. User enters name and interest levels
2. ML model predicts suitable career
3. Special rule logic improves prediction accuracy
4. Career description and skill analysis shown
5. Student data stored in database (CSV)
6. Gemini AI generates 3-month roadmap
7. User downloads personalized career report
